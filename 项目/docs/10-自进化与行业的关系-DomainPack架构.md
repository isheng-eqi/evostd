# 10 · 自进化与行业的关系：行业是"目标函数供应商"

> 本文回答一个问题：**自进化本质上和选行业有关系吗？**
> 结论先行：**关系不在行业本身，而在"这个行业里能不能造出一个廉价、可信、外部独立的验证器"。**
> 行业不进入自进化的回路结构，行业只提供回路的**目标函数**。

---

## 一、把回路的数学结构写出来，行业在哪一格就一目了然

任何自进化系统都是这五步，**与领域无关**：

```
候选生成 (mutator)  →  评估 (verifier)  →  选择 (selection)
        ↑                                          ↓
   元层改进 (meta)   ←   存档 (archive)  ←──────────┘
```

逐格问"行业进来了吗"：

| 环节 | 是否依赖行业 | 说明 |
|---|---|---|
| 候选生成 | **否** | 变异算子就是"读父代 + 读失败反馈 → 产新版本"。换行业只换提示模板里的名词 |
| **评估** | **★ 是** | **唯一真正依赖行业的一格**。因为"什么算对"由该行业的权威文本规定 |
| 选择 | 否 | 岛屿/存档/谱系价值（CMP）是通用机制 |
| 元层改进 | 否 | 改的是搜索策略本身，与领域正交 |
| 存档 | 否 | 存的是 (候选, 分数, 血统) |

**所以：行业只作用于一格——评估。** 但这一格恰恰是整个回路的命门。

---

## 二、为什么"评估"这一格如此关键：验证瓶颈

这是我调研全部前沿工作后收敛出的第一条硬规律：

> **没有廉价、可信、可判定的验证器的地方，不会发生自进化。**

有硬证据的成功案例全部落在"答案可被程序判定"的领域：AlphaEvolve（用户必须提供 `evaluate` 函数）、FunSearch（同上）、Absolute Zero（代码执行器）、R-Zero（数学题自洽性）、DGM/HGM（SWE-bench/Polyglot 的通过率）。
反过来，把验证器换成模型自己的系统（Self-Refine、Self-Rewarding）是后来被打得最狠的：迭代 10 轮后自评偏见从 8.06 涨到 14.6，而**人类评分显示质量并没有可测量的提升**——它只是自认为在提升。

因此**行业的唯一相关性**可以精确表述为三个问题：

| 判据 | 好的行业 | 坏的行业 |
|---|---|---|
| **① 结果可不可判定？** | 有权威文本规定了"什么是对的" | 只能靠主观判断 |
| **② 验证一次多贵？** | 毫秒~秒级、纯 CPU、确定性 | 需要人、需要实验、需要几十分钟 GPU |
| **③ 能不能 held-out？** | 有一批永远不进进化集的题 | 全部数据都得用来进化 |

**三条全过 = 这个行业能做自进化。任一条不过 = 这个行业只能做"自动优化"。**

---

## 三、四个候选行业在这把尺子下是同一类

用上面三问去量赛题允许的四个行业：

| 行业 | 权威文本（=验证器来源） | 可判定性 | 成本 | 结论 |
|---|---|---|---|---|
| 医疗 | 临床指南 / 专家共识 / 诊疗规范 | 条款级可判定 | 秒级 | ✅ 过 |
| 金融 | 监管办法 / 业务规程 / 会计准则 | 条款级可判定 | 秒级 | ✅ 过 |
| 制造 | 安全技术规范 / 检维修规程 / 工艺标准 | 条款级可判定 | 秒级 | ✅ 过 |
| 政务 | 政策文件 / 办事指南 / 数据元标准 | 条款级可判定 | 秒级 | ✅ 过 |

**注意它们的共同点：都存在一部"权威文本"，把"什么是对的"写下来了。**

这就是验证器的来源——也是**沉睡数据资产**之所以能"被激活"的原因：
沉睡的不是数据本身，是**数据背后那部没被机器读懂的规范**。

> **结论一：从自进化的角度，这四个行业没有本质区别。它们都是"有权威文本可作验证器"的行业。**

## 四、那行业到底影响什么？影响三件与自进化无关的事

| 影响项 | 对应赛题评分 |
|---|---|
| 评委能不能一眼看懂价值 | 业务价值 25% |
| 多模态数据的形态与可得性 | 要求① 的完成度 |
| "沉睡存量数据资产"的故事讲不讲得通 | 要求②+④ 的叙事强度 |

**这三件事决定分数，不决定回路能不能跑。**
所以正确的决策顺序是：

```
第一步（准入，一票否决）：这个行业能不能造出 <10 秒、同输入同输出、外部独立的验证器？
        —— 四个行业都过。所以现在不必选。

第二步（排序，决定分数）：演示效果 / 数据可得性 / 故事强度 / 与既有工作的差异度。
        —— 这一步可以等内核跑通之后再定。
```

## 五、由此得出的架构决策：Domain Pack（领域包）可插拔

既然行业只提供"验证器 + 语料 + 标准 + 叙事"，那就把它做成一个**可插拔的适配层**，内核完全不依赖它：

```
┌───────────────────────── 自进化内核（与行业无关）─────────────────────────┐
│  mutator  变异算子（LLM 改写 / 结构扩张）                                  │
│  verifier 验证器接口  ← 唯一被行业实现的地方                                │
│  gate     对照闸门（guided vs withheld 配对裁决）                          │
│  archive  岛屿存档 + 血统 + CMP 估计                                       │
│  audit    审计（对抗探针 / 代理-真实落差 / 塌缩检测）                       │
│  ledger   追加式台账（可回滚）                                             │
└───────────────────────────────┬───────────────────────────────────────────┘
                                │  只通过一个窄接口调用
        ┌───────────────────────┴───────────────────────┐
        ▼                                               ▼
┌── Domain Pack：制造 ──┐                    ┌── Domain Pack：金融 ──┐
│ corpus/   规程与工艺卡 │                    │ corpus/  监管办法     │
│ standards/ GB 与行标   │                    │ standards/ 监管条款    │
│ verifier.py 条款判定   │                    │ verifier.py 合规判定   │
│ narrative  沉睡资产故事│                    │ narrative 合规成本故事 │
└────────────────────────┘                    └────────────────────────┘
```

**一个 Domain Pack 只需要实现四样东西**：

```python
class DomainPack(Protocol):
    name: str
    def corpus(self) -> list[Document]: ...          # 语料（多模态）
    def standards(self) -> list[Standard]: ...       # 要与之对齐的标准体系
    def build_verifier(self) -> Verifier: ...        # ★ 外部、确定性、可 held-out
    def narrative(self) -> str: ...                  # 业务价值叙事（给人看的）
```

**这个架构本身就是一个可讲的卖点**，直接对应评分项④"通用推广价值"：
> 换行业 = 换一个 Domain Pack，自进化内核一行不改。

---

## 六、这对我们的项目意味着什么（三条可执行结论）

1. **现在不必决定行业。** 先用一个"人造但可判定"的 Domain Pack 把内核跑出真实的代际上升曲线——这证明回路是真的，且完全不依赖行业选择。
2. **行业决策推迟到内核跑通之后**，按"演示效果 / 数据可得性 / 故事强度"排序来选，那时我们手里已经有曲线可作为选型的筹码。
3. **不许出现"用模型自评当验证器"**。评分只能来自 Domain Pack 里的确定性程序；LLM 只允许做两件事——**生成候选**和**诊断失败**。这条写进代码，不靠自觉。

---

## 七、一句话回答

> **自进化与行业的关系，是优化算法与目标函数的关系。**
> 算法不认识目标函数；但没有目标函数就没有优化。
> 行业对我们唯一的意义，是**它把"什么是对的"写下来了**——
> 于是沉睡在规范文本里的判断标准，可以被编译成一个廉价、可信、可判定的验证器。
> **能被编译成验证器的行业，才是能做自进化的行业。四个候选行业都合格。**
