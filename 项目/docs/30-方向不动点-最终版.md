# 30 · 方向不动点（最终版）

> 本文把方向一次性推到**再松一步就自我矛盾**的位置。
> 不是"想不出来了"，而是**证明了这个体系的定义性边界在哪**。
> 沿革：docs/21（一阶）→ docs/22（二阶）→ docs/23（实验三发现）→ docs/24（三阶提案）→ docs/25（三阶被否，瓶颈在裁决）→ docs/26（建议锁版）→ **docs/30（不动点）**

---

## 一、不动点论证：哪一步不能再松

自进化系统的每一次"放松假设"，都是在把更多东西交给系统自己决定。逐层推：

| 放松到哪一层 | 系统能自己决定什么 | 后果 |
|---|---|---|
| 一阶 | 在固定判据下，改产物 | 自动优化，**必撞天花板**（平稳性二分） |
| 二阶 | 改判据 + 改判据语言 | 辨别力边界扩张 ✔ |
| 二阶·补 | 改**裁决规则** | 学会"怀疑"而非"相信命中" ✔ |
| 三阶 | 改索取策略（该问人什么） | 可做，但**收益远小于裁决修正**（docs/25 实测） |
| **再上一层** | **系统自己决定"什么算对"** | ❌ **自我矛盾** |

**最后一行是定义性边界，理由是三段论：**

1. "改进"这个概念要求存在一个**独立于系统的比较基准**；
2. 若系统自己提供这个基准，则"改进"退化为"变化"——任何变化都能自称改进；
3. 于是体系崩溃：**没有外部真值，就没有"改进"可言，也就没有自进化。**

> ## ∴ **"最终裁决者必须永远在系统之外"是不可再松动的假设——它是自进化的定义，不是一条工程约束。**

**这就是不动点**：不是因为没有想法了，而是因为**再松一步，被定义的东西就消失了**。

---

## 二、不动点的完整形态

既然"外部裁决者"不可去除，那么全部工程问题就变成一句话：

> **把外部裁决者压缩到最小，把其余一切交给系统。**

```
┌─ 外部真值层（不可进化，且被压到最小）──────────────────────────┐
│                                                                │
│  ① 硬锚点：标准文本里**机械可判定**的部分                       │
│     受控词表 / 取值域 / 必填清单 / 条款编号关系 / 附录示例        │
│     —— 免费、外部、无争议、**不需要人**                          │
│                                                                │
│  ② 软确认：标准里**需要解释**的部分，由人一次性确认               │
│     —— 最贵，但被①挤到最小区域                                  │
│                                                                │
│  ③ 裁决不变量：系统的任何提案，其裁决必须发生在它够不着的地方      │
└────────────────────────────────────────────────────────────────┘
                              ↓ 只在这里读真值
┌─ 可进化层（系统可以改这一切）──────────────────────────────────┐
│  L1  裁决规则      消融归因 / 证伪优先 / 反事实                 │
│  L2  判据库        含**判据语言自身的扩张**                     │
│  L3  判据的对象    从"一条资产"升级到"资产之间的图/结构"         │
│  L4  产物          本体 / 资产标识 / Skill 模板 / 检索-推理编排  │
│  L5  索取策略      该问人什么（收益小，但可做）                  │
└────────────────────────────────────────────────────────────────┘
```

**关键洞察：外部真值不是"一个东西"，而是一条成本谱。**
方向迭代的**全部内容**就是：**把真值从贵的一端（人确认）不断搬到便宜的一端（机械可判定）**。

---

## 三、把"低资源"变成可优化的目标（这是不动点带来的最大收获）

原来"低资源"是个约束（数据少、标注少）。在不动点框架里，它是**两个可测指标**：

| 指标 | 定义 | 方向 |
|---|---|---|
| **硬锚点覆盖率** | 标准中可机械判定条款 / 全部条款 | ↑ 越高，人越省 |
| **人工确认密度** | 每提升一单位辨别力所需的人工确认次数 | ↓ 越低，越"低资源" |

> **"低资源"不是忍出来的，是搬出来的**——把真值从"人点头"搬到"条款自证"。

这也直接回答了一个一直悬着的问题：**为什么这个方向天然适配"低资源领域"？**
因为低资源领域的痛点不是没数据，是**没标注**；而标准文本里恰好沉睡着大量**自证的标注**。

## 四、不动点下的层级表（最终形态）

| 层 | 谁在进化 | 裁决者 | 人的角色 | 状态 |
|---|---|---|---|---|
| L1 | **裁决规则** | 硬锚点 + 软确认 | 一次 | ★ 被实验推为主攻（docs/25） |
| L2 | **判据库 + 判据语言** | 同上 | 一次 | ✅ 已验证（F1 0.6154→1.0000，含文法扩张） |
| L3 | **判据的对象（点→图）** | 同上 | 一次 | ⏳ 待验证 |
| L4 | 产物（本体/标识/Skill/编排） | 判据库 | 写规则 | ✅ 已验证（1.0000 / 0.9790） |
| L5 | 索取策略 | held-out 锚点 | 回答 | ⏸️ 收益小，降级 |
| — | **最终裁决者** | — | — | ❌ **不可进化（定义性边界）** |

## 五、这个方向为什么同时是最深和最实用的

| 视角 | 它成立的理由 |
|---|---|
| **理论** | 它把"自进化"收敛到一个可证的定义性边界上，而不是靠不断加机制 |
| **2026 前沿** | 它正踩在公认瓶颈上（验证器），且有反直觉硬结论（下游分数无法认证验证器） |
| **安全** | 唯一的不可动项就是安全边界：**系统可提案一切，但裁决发生在它够不着的地方** |
| **低资源** | 把"低资源"从约束变成两个可优化指标 |
| **赛题** | 赛题三的每一条要求都落在某一层上，**它是这个框架的实例，不是约束** |
| **可证伪** | 每一层都有明确实验；**没通过就砍**（三阶就是这么被砍的） |

## 六、再往上还有没有？

**没有。** 而且我能给出证明而不是感觉：

- 再往上的唯一可能是"系统自己当最终裁决者"；
- 那会让"改进"退化为"变化"（第一节三段论）；
- **所以这个方向不是"暂时没想到更深的"，而是"更深的一步会取消这个学科"。**

**框架是闭合的。** 剩下的全是工程问题——而工程问题，就该跑实验。

---

## 七、锁版声明

> ## **把权威标准编译成可执行判据；把外部真值从"人确认"不断搬到"条款自证"；
> ## 让判据库在最小外部真值上自己长大（含判据语言的扩张与对象的结构化）；
> ## 裁决用消融归因与证伪优先，不用"命中"；
> ## 产物（本体/标识/Skill/编排）在这个判据库上进化；
> ## 而最终裁决者永远在 agent 够不着的地方——这是定义，不是约束。**

**此后不再新增方向。** 任何新想法，一律先写成可证伪检验，跑出数据再决定纳入或砍掉。
